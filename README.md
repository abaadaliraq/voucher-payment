# بيت التحفيات | إدارة المصروفات

**HOUSE OF ANTIQUES | EXPENSE MANAGEMENT**

## التشغيل

افتح `index.html` مباشرة في نافذة عادية من Chrome أو Edge. أبقِ المجلدين `css` و`js` بجانب الملف. يعمل التطبيق محلياً باستخدام HTML وCSS وJavaScript وIndexedDB.

استخدم المتصفح وملف التعريف ومسار الملف نفسه عند إعادة الفتح. تختلف طريقة التعامل مع تخزين الملفات المحلية بين المتصفحات. صدّر نسخة JSON قبل نقل المشروع أو تبديل المتصفح، ثم استوردها من «النسخ الاحتياطي والإعدادات». يمكن أن يؤدي مسح بيانات المتصفح إلى فقدان السجل المحلي.

## تسجيل العمليات

1. افتح «سجل المصروفات» واضغط «مصروف جديد». أدخل الإجمالي أو أضف بنوداً لحسابه تلقائياً.
2. افتح تفاصيل المصروف واختر «تسجيل دفعة». يُحتسب المدفوع والمتبقي من مبالغ الدفعات المسجلة.
3. اختر «إصدار سند» بجانب الدفعة. يظهر مبلغ الدفعة في السند، وتُحسب الدفعات السابقة بحسب ترتيب تسجيلها. تُحفظ بيانات السند عند الإصدار وتبقى المعاينة مطابقة للأصل بعد تغيير المصروف أو بيانات المؤسسة.
4. اختر «طباعة السند» أو «حفظ PDF». للحفظ، اختر «حفظ بتنسيق PDF» من نافذة طباعة المتصفح. مقاس الورق A4 عمودي.
5. لتصحيح دفعة لها سند صادر، ألغِ السند مع تدوين السبب، ثم عدّل الدفعة من تفاصيل المصروف وأصدر سنداً جديداً. يظهر السند الملغى في سجل السندات.

يبدأ النظام بسجل مالي فارغ. لاختبار الحسابات، سجّل مصروفاً بقيمة 5,000,000 دينار، ثم دفعتين بقيمة 1,500,000 و1,000,000 دينار. المتبقي بعد الأولى 3,500,000 وبعد الثانية 2,500,000. قيمة سند الدفعة الثانية 1,000,000 دينار.

## التقارير والنسخ الاحتياطي

- تعمل فلاتر الفترة على تاريخ تسجيل المصروف، وتعرض الدفعات المرتبطة بالمصروفات المطابقة.
- يصدّر التقرير النتائج المصفّاة وملخصاتها إلى CSV بترميز UTF-8 مع BOM لدعم العربية في Excel.
- صدّر نسخة JSON دورياً. يتطلب الاستيراد ملفاً صالحاً وتأكيد استبدال البيانات. يحتفظ التطبيق بأعلى رقم تسلسلي محلي عند الاستعادة لكي تستمر الإصدارات الجديدة بعده.

## الملفات

- `index.html` مدخل التطبيق.
- `css/style.css` الواجهة، و`css/print.css` طباعة سند الصرف.
- `js/database.js` معاملات IndexedDB، و`js/finance.js` قواعد السجل والتحقق من البيانات.
- `js/vouchers.js` قالب السند وكتابة المبلغ، و`js/reports.js` الفلاتر والتجميع والتصدير.
- `js/app.js` التفاعل والتنقل والنماذج، و`js/utils.js` تنسيق الأرقام والتواريخ والملفات.

## تحديث السجل على GitHub Pages

تقرأ نسخة `github.io` السجل من `data/ledger.js` وتعرض نفس البيانات في كل المتصفحات. بعد تعديل الملف، ارفع التحديث إلى الفرع المستخدم للنشر. زر «تصدير ملف السجل JS» في النسخة المحلية يجهّز هذا الملف مباشرةً من المصروفات والدفعات المسجلة.

الملف المنشور قابل للقراءة من أي شخص يستطيع فتح الموقع. ضمّن فيه فقط البيانات التي تقصد نشرها. احتفظ بالنسخة المالية الكاملة في مكان خاص إذا كان الموقع عاماً.

### إضافة مصروف ودفعة إلى الملف يدوياً

داخل الكائن `globalThis.publishedLedger`، أضف سجلاً إلى مصفوفة `expenses` باستخدام رقم مصروف جديد وتصنيف موجود في `categories`. هذا مثال، بدّل الأرقام والبيانات قبل استخدامه:

```js
{ id: 101, date: '2026-11-13', categoryId: 1, description: 'تجهيز حديقة',
  vendor: 'المورد', total: 5000000, items: [] }
```

إذا سددت دفعة، أضفها إلى مصفوفة `payments` برقم دفعة جديد، وضع رقم المصروف نفسه في `expenseId`:

```js
{ id: 201, expenseId: 101, date: '2026-11-13', amount: 1500000,
  method: 'cash', recipient: 'المستلم', notes: '' }
```

حدّث `counters.expense` و`counters.payment` إلى أعلى رقم مستخدم لكل منهما إذا تجاوزت أرقامهما الحالية. يحسب التطبيق المدفوع والمتبقي تلقائياً. استخدم `cash` للنقد أو `transfer` للتحويل. لإصدار سند من الواجهة، استخدم النسخة المحلية ثم صدّر ملف السجل مجدداً.
